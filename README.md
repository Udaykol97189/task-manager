# Docker Task Manager

A production-oriented task management application built with React,
FastAPI, PostgreSQL, and Docker.

## Status

🚧 Under Development

## Technology Stack

- React.js
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Docker
- Docker Compose
- Pytest

## Architecture

React → FastAPI → PostgreSQL

## Development

The project is being developed incrementally from requirements to
containerized production architecture.
